01 — The building blocks

Three ideas.
One bigger picture.

AI is a broad field. Machine learning is one way to build it, and neural networks are one family of learning models. Start with the distinctions that make everything else easier to understand.

01 / INTELLIGENCE

Artificial Intelligence

AI describes computer systems designed to perform tasks that usually need human-like abilities, such as understanding language or recognising images.

02 / LEARNING

Machine Learning

Machine learning lets a system find patterns in examples and use those patterns to make predictions, rather than relying only on hand-written rules.

03 / NETWORKS

Neural Networks

Neural networks are machine-learning models made from connected layers that can learn complex relationships from data.

02 — A simple learning path

From examples
to understanding.

Follow the flow from raw examples to a useful result. These are the broad stages behind how a machine-learning model is developed and used.

01 / INPUT

Give it examples

Collect useful, representative data. The quality of examples shapes what a model can learn.

02 / LEARNING

Find the patterns

During training, a model adjusts its internal parameters to reduce errors on the examples it sees.

03 / OUTPUT

Make a prediction

After evaluation, the model can use what it learned to make predictions on new information.

03 — Quick answers

Curiosity is
a good place to start.

A few useful distinctions to keep in mind as you explore the field.

Is AI the same as machine learning?

No. AI is the broader field; machine learning is a set of techniques within AI that learn patterns from data.

Does a model understand like a person?

Not necessarily. Models calculate patterns from training and input data. Useful output does not imply human experience or understanding.

Why do training data and testing matter?

Testing on data the model did not train on helps estimate how well it may perform on new examples and can reveal overfitting.
